D05: Issue precheck ignores member eligibility

GitHub issue: https://github.com/MuhammadAbdullah8741/SQE-Submission/issues/7
Severity: Medium
Priority: P2
Status: Fixed and verified
Risk: R02
Category: API contract

Reproduction / review:
Request issue/precheck with a known ISBN and an empty, unknown or ineligible member ID. Expected: eligibility error. Observed: stock availability returned without checking member.

Evidence:
IssueReturnService.precheckIssue; api-results.json 52/52 pass

Root cause:
Precheck implemented stock lookup while its description promised limit/fine checks.

Correction:
Shared read-only eligibility validation with the issue operation, including member, limit, fines and duplicate-loan checks.

Triage:
Regression passes for invalid member partitions; retain normal issue operation as the state-changing authority.
